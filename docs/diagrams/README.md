# Architecture และ User Journey

อินโฟกราฟิกภาษาไทยสำหรับรายงานโปรเจกต์ UNNAMED Chatbot สร้างด้วย built-in image_gen วันที่ 10 ตุลาคม 2026 ตรวจข้อความหลัก ราคา ระยะเวลา และลำดับการทำงานเทียบกับ implementation แล้ว

- [Architecture](architecture-v1.png): สถาปัตยกรรมเป้าหมายของโหมด connected พร้อมคิว, guards, LightRAG, OpenRouter และเส้นทางภาพ ภาพนี้ไม่ใช่หลักฐานว่า deploy หรือเชื่อมบริการภายนอกสำเร็จแล้ว
- [User Journey ฉบับล่าสุด — ลูกค้าผู้ชาย](user-journey-v2-male.png): ตัวอย่างการถามข้อมูลร้าน การขอคำแนะนำหลายรอบ การส่งภาพเมื่อเปิดใช้งาน และกรณีปฏิเสธ/ส่งต่อให้ช่างประเมิน
- [User Journey ฉบับแรก](user-journey-v1.png): เก็บไว้เป็นต้นฉบับก่อนแก้ตัวละคร
- [Prompt สำหรับแก้เป็นผู้ชาย](user-journey-v2-prompt.json)
- [Prompt ที่ใช้สร้างและแก้ภาพ](image-prompts.json)

ทั้งสองไฟล์เป็น PNG แนวนอน 16:9 เส้นทางรับภาพยังปิดไว้เป็นค่าเริ่มต้นตามโค้ด ระบบให้ข้อมูลเท่านั้น ยังไม่จองคิวและไม่เชื่อมระบบร้านเดิม
